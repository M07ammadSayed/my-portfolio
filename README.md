## 🚀 Overview

This is a demonstration of **Secure Coding** and **Modern Frontend Architecture**.  
Built to showcase the transition from **Full-Stack Development** to **Application Security**, featuring a zero-trust approach to UI components and high-end performance optimization.

## 🛠️ Tech Stack & Security

-   **Core:** Next.js 15 (App Router), TypeScript, React 19.
-   **Styling:** Tailwind CSS, Framer Motion (Hardware-accelerated animations).
-   **Security First:** - Strict **CSP (Content Security Policy)** & Security Headers via `next.config.mjs`.
    -   Secure Link attributes (`rel="noopener noreferrer"`) for all outbound traffic.
    -   `security.txt` compliance (RFC 9116) for vulnerability disclosure.
-   **Performance Engineering:** - **Code Splitting:** Dynamic imports for heavy components (Skills, Projects).
    -   **Critical Path:** Minimized Total Blocking Time (TBT) to < 50ms.
    -   **Conditional Rendering:** Disabling heavy Canvas animations on low-end/mobile devices.

## ⚡ Key Features

-   **Cinematic UI:** Meteor effects & 3D Tilt cards with zero layout shift (CLS: 0).
-   **PWA Optimized:** Full offline support with custom Service Workers and `manifest.ts`.
-   **SEO & Analytics:** Dynamic OpenGraph metadata & optimized Google Tag Manager loading.
-   **Accessibility:** 100% Lighthouse Score (Aria-labels, Semantic HTML5).
